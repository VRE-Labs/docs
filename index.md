# Obscura Docs

## Overview

**Obscura — Create Your Persona, Set Your Stage**

Obscura is a live, voice‑first community platform for hosting real‑time conversations, building persistent communities, and sharing ephemeral moments. Create a persona, host stages, moderate spaces, and connect through voice and text—designed for privacy-minded communities, creators, and small groups who want a low‑friction live audio experience.

## Key Features
- **Live Voice Stages:** Host moderated or open stages with queueing, handoffs, and audience controls.  
- **Profiles & Personas:** Lightweight profiles focused on display name and avatar for fast identity discovery.  
- **Text Chat & Threads:** Persistent text alongside live audio for links, notes, and followups.  
- **Access Control:** Register using access or referral codes to keep communities gated and intentional.  
- **Moderation Tools:** Role-based controls for moderators and owners, with in-app actions for kicking, banning, and moderating conversations.  
- **Embeds & Previews:** Rich link previews and cached embeds for performant feeds.  
- **Privacy & Security:** Minimal required data, upcoming MFA for sensitive actions, and server‑side checks for safe operation.  
- **Extensible API:** Lightweight backend endpoints for automation, integrations, and tooling.

## Why Obscura
Obscura focuses on low-latency, human‑centered live audio experiences without complexity. It balances real‑time presence with persistent context (chat, embeds, changelogs) and tools for safe, intentional communities. Ideal for creators, event hosts, and communities that value voice-first interaction plus lightweight moderation.

## Get Started
- Register with an access or referral code, or contact an admin for invites.  
- Join a stage to listen, request to speak, or host your own session.  
- Use channel options to publish announcements or lock channels to moderators only.  
- Visit the docs (this site) for admin setup, API references, moderation guides, and deployment instructions.

## Support & Contribution
Found a bug or want a feature? Open an issue or submit a PR. 
For account or access problems, contact an admin listed in the community or consult the Troubleshooting guide.
